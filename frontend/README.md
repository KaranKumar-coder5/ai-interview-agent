# frontend

React + TypeScript + Vite UI for the AI Interview Agent.

- `npm run dev` — Vite dev server (proxies `/api` and `/health` to the backend on `:3000`).
- `npm run build` — type-check + production build to `dist/`.
- `npm run typecheck` — TypeScript project-build check (no emit).
- `npm run lint` — Oxlint.

UI screens are intentionally not implemented yet. See the root `README.md`.
